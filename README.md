# mwendavano.com

Static company website for Mwendavano Holdings Limited. No build step: upload this folder as the web root.

| File | What |
|---|---|
| `index.html` | The whole site (styles and script inline; fonts from Google Fonts) |
| `img/` | App screenshots for the carousel (Dukani Mauzo, Dukani Wafanyakazi; demo data only) |
| `js/` | Page scripts (kept out of index.html so the Content-Security-Policy can allow only this site) |
| `favicon.svg` | Logo mark |
| `og.jpg` | Link preview image (1200×630) for WhatsApp, Facebook, LinkedIn |
| `robots.txt`, `sitemap.xml` | Search engines |

Canonical URL and sharing tags assume `https://mwendavano.com/`. Change them in `index.html` if the site lives elsewhere.
The contact form opens WhatsApp to +255 789 947 608 with the visitor's message filled in; no server needed.
